## 2. Mastering the Command Line Interface (CLI) – Learning Completed

Learned the concepts and commands used to manage files, directories, search data, and perform operations through the Linux command line.

### Topics Learned
* Creating and managing files and directories.
* Copying, moving, renaming, and deleting files.
* Understanding hard links and symbolic links.
* Working with wildcards and command substitution.
* Searching files and directories.
* Filtering and searching text using commands.
* Using pipes and output redirection.
* Sorting and manipulating text and CSV data.
* Extracting specific information from files.

### Commands Learned
* **File management:** `touch`, `mkdir`, `cp`, `mv`, `rm`, `rmdir`

* **Text processing:** `sort`, `cut`, `sed`, `wc`
* **Output handling:** `head`, `tail`, pipes (`|`), redirection (`>` and `>>`)
* **Other utilities:** `nano`, `tree`, `scp`
