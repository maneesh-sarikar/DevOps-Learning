1. Getting Started with Linux

• Understood the Linux ecosystem and the core role of the Linux Kernel.
• Learned about kernel modules and modular system architecture.
• Explored open-source Linux and its collaborative development model.
• Studied major Linux distributions: Ubuntu, Debian, Fedora, RHEL, Kali Linux, and Amazon Linux.

2. Linux grep Command – Operational Pattern Matching

• Learned the purpose, syntax, and practical usage of the grep command.
• Practiced searching for specific keywords and phrases within files.
• Understood Standard Input (stdin) behavior and why grep waits for input when no file source is specified.
• Explored recursive searching using -r and -R (including symbolic link handling).
• Used -l to display only matching filenames, -i for case-insensitive searches, and -n to display line numbers.
• Learned Extended Regular Expressions (-E) and practiced pattern matching with ?, *, [0-9], and |.
• Mastered special character handling and proper quoting for patterns containing spaces and apostrophes.
• Practical Lab: Pluralsight – Objective 1: Finding Objects Anywhere Within a Linux File System.

3. Linux Text Streams and Pipelines

• Practical Lab: Pluralsight – Objective 2: Interacting with Text Streams.
• Used cat to output file contents and chained it with grep via pipelines (|).
• Practiced filtering content from git/README.source using the keyword extracted.
• Applied contextual filtering flags:
	• -A – Display lines after a match.
	• -B – Display lines before a match.
	• -C – Display surrounding context lines.
• Understood how standard output (stdout) from one command passes directly into standard input (stdin) of the next.

4. Counting, Output Redirection, and File Comparison

• Used wc to count lines, words, and bytes.
• Distinguished between counting matched content lines versus counting matched filenames.
• Practiced output redirection using > (overwrite) and >> (append).
• Saved recursive search outputs into lowercase.txt and uppercase.txt.
• Used diff to compare variations in outputs generated by -r and -R.

5. Linux Process Inspection and Filtering

• Learned core process concepts: Process IDs (PID), resource utilization, and process ownership.

• Practiced regex line anchors with grep root, grep ^root (beginning of line), and grep d$ (end of line).
